# 序章 v11：神异地标与生物原型

## 本轮方向
在 v10 废墟后方增加“矿化巨兽遗骨环抱古树”的原创祭场。以巨大尺度、遗骨轮廓、铜赭稀疏叶冠和玉质异草建立异常生态，不依赖全场发光。白耳猿形生物参考《山海经》狌狌的白耳特征，属于游戏原创演绎。

## 交付
- 主场景：`art/prologue_terrain/prologue_terrain_v11.blend`。
- 独立 Collection 素材库：`art/shanhai_ecology/v1/`，共五类：古树、单根遗骨、盘根、异草、白耳猿形生物。通过 Blender 的 Append / Link 选择 Collection 复用；不是单独布置了相机的展示场景。
- 三只异兽实例，帧 1–180 包含转头观察、轻微呼吸。当前是物体层级动画原型，没有完成骨骼蒙皮、行走、战斗、AI 或物理行为。
- `sanctuary_v11.png` 为地标整体图；`village_landmark_v11.png` 为村落方向透视视线检查，不代表最终游戏相机；`simian_v11.png` 和 `simian_observation_v11.gif` 用于生物与动作检查。

## 检查与限制
重开 v11，验证 v10 文件哈希不变、原有链接路径有效；检查转头角度变化约 0.33 弧度和呼吸缩放，输出六帧动作证据。修正初次渲染中的面部父子变换、身体接缝和脚底高度。

这是神异方向的第一轮场景原型，并非写实精模验收完成。仍需：遗骨断裂与骨质结构雕刻、古树分叉融合与根部贴地、生物头部解剖与毛发、四肢运动和足底接触打磨。现有普通树叶与地表也仍有明显风格化痕迹。

保持序章东坡原定狌狌试炼设计；祭场观察个体仅增加生态表现，不改变试炼位置与主线。本轮只在 Blender 内优化，未接入 Godot，未提交推送。

## 复现顺序
1. Blender 后台运行 `tools/build_shanhai_sanctuary.py`。
2. 运行 `tools/check_shanhai_sanctuary.py`，检查并生成动作帧。
3. 运行 `tools/polish_shanhai_tree.py`，保存细枝叶冠与更新场景预览。
以上命令需带 `--python-exit-code 1`。
