# 《山海录：归途》支线与全收集设计

版本：0.1（设计提案） · 2026-09-07<br>
关联：[主线及多结局](shanhai-story.md) · [审阅记录](shanhai-story-review.md) · [玩法整合、回访与保存](shanhai-gameplay.md)

## 1. 目标与时长

支线表现当地人的生活与山海生态，让回家路上认识的人有自己的故事。每条支线至少包含一个观察或行动判断，以及一个可见结果。不能全部写成取物、清怪、交差。

建议首批完整支线 12 条，按首次正常完成计算共 600 分钟（10 小时）。主线约 30 小时，主线加这批支线约 40 小时；完整收录再增加约 10～15 小时的非重复探索，合计约 50～55 小时。图鉴首次发现、支线要求的观察和沿路采样均计入发生它们的任务时间，不重复累加。旧的 50～60 小时估计收窄为待测试目标，不用等待稀有刷新补时长。

以下任务人物、地名与事件均为原创提案。支线奖励可改变援助、局部道路、人物后日谈或补给便利，不控制主线必要技能或四条结局的基本可达性。

## 3. 任务流程

### S01 不迷的归路

触发：P0 主线获落脚点后，采药人委托标出可供学徒往返的路。主线救援学徒已经结束，支线不重复同一次救援。

流程：比较三处路标与迷榖生长位置 → 实走安全与危险岔道 → 选择并标定路线 → 带学徒走一小段验证。误判触发折返提示，可修正；不永久困住 NPC。

完成与奖励：验证终点到达且路标连续，更新安全路线；解锁一个地区观察提示和采药人对白。不能把主线寻路功能锁在这条支线。错过 P0 可在原聚落补做。

### S02 篮中留种

触发：发现药圃缺苗和过度采摘痕迹。

流程：对比成熟与未成熟植株 → 观察授粉或种子散布 → 从成熟株采样 → 选择保留野外种群或将样本交给药圃。两种选择都有明确生态说明，不设秘密善恶分。

完成与奖励：交付可再生样本并建立观察点，获得植物资料与补给便利。植物恢复采用离区后任务阶段更新，不需现实等待；误采有补充地点，不因有限种子软锁。此任务不是完整种植经营系统。

### S03 渡口的旧水线

触发：P1 主线已经辨认改道，渡路人仍要安排日常补给。

流程：检查岸痕、搁浅物和旧桥基础 → 实走山路与浅滩 → 清理所选路线的具体障碍 → 帮助一次运送。

完成与奖励：运送抵达，开放补给点或步行捷径，另一条仍可作为普通探索路。洪水判断错误可换路，运输失败从该段重试。主线通向青丘的通路不依赖本任务。

### S04 无声的迁徙

触发：渡口附近出现空巢与异常足迹；不要求先接 NPC 任务才能识别。

流程：沿三种不同证据追踪 → 找到被阻断的通行带 → 选择清理障碍引导迁徙，或帮助聚落设置绕行边界 → 观察种群到达栖息地。

完成与奖励：记录迁徙路径与当前栖息地，获得两处物种线索。护送目标受惊则退回安全点，可重试；不让唯一动物死亡。当地人评价路线成本，不能让一个选择同时获得两套互斥世界状态。

### S05 狐影与空屋

触发：P2 主线失踪事件结束后，一户人家仍不愿返回旧屋。

流程：分辨居住痕迹、兽迹与人为驱赶标记 → 找到隐瞒布设陷阱的人 → 拆除陷阱或协商迁移住处 → 回访。

完成与奖励：居民安置或回家，守望者增加信任与对白。证据不足可继续调查，不因一次对话猜错永久失败。不重复主线九尾狐领地战，也不否认主线已经确认的危险。

### S06 留给后来人的路

触发：发现前任持书人在旧营地留下的路线标记。

流程：追踪标记 → 在坍塌路径中战斗或绕行 → 找到他曾帮助外来者的证据 → 决定修复标记或将危险标记撤除。

完成与奖励：一个旧路捷径与营地记录；第三章对谈可引用这段经历。记录表明他曾经救人，不替其后来的伤害免责。不接任务就先读营地记录也应补登记步骤。

### S07 根下的名字

触发：P3 获得事故真相后，遇见寻找家人遗物的居民。

流程：核对遗物标记与口述 → 找到被根系阻住的旧居 → 调查撤离痕迹而非搜集随机遗骨 → 把可确认的消息和遗物交还。

完成与奖励：地区纪念地点与人物后日谈，提供旧水位旁证。关键道具独立于普通背包，不可误卖；它证明具体人的遭遇，不新增会推翻主线的隐藏事故原因。

### S08 不能寄出的信

触发：P3 与前任对谈后，看到未寄出的书信记录。

流程：获得其许可或从公开寄存记录找到旧地址线索 → 走访两处已开放地点 → 确认收信人无法从这里联络 → 决定归还原信或留下经同意的抄本。

完成与奖励：解锁一段私人对谈，在归乡或留山尾声中出现信件回应。任务不能证明故乡已毁、亲人死亡等尚未确定的背景。前任离开后由寄存箱接收结果，后续对白改为书面回应，不能失去交付对象。

### S09 空巢之下

触发：P4 发现巢地被采集活动扰动，收集者也有补给需求。

流程：辨认空巢而非废巢 → 找出可替代的采集地 → 在生灵归巢前处理捕食者或驱扰装置 → 看见巢地重新使用。

完成与奖励：观察点、地方物种资料和人物后日谈。凤凰是远景主线存在，支线围绕普通鸟类或小型异鸟，不增加第二个凤凰首领。归巢由任务阶段驱动，错过演出可在观察点复看。

### S10 火后第一株

触发：P4 主线恢复水道之后，一小片烧灼地仍未恢复。

流程：比较光照、土壤湿度与种子来源 → 调整小范围遮蔽物或水路 → 从已有可再生地点取样 → 离区再回访。

完成与奖励：新观察点和植物再生周期注释。该地点不产出唯一绝版物种；选错环境可修正。只改变局部场景阶段，不要求实时土壤模拟，也不取代主线水系恢复。

### S11 等不到天亮的人

触发：P5 从观测站收到被困者的路线记录。

流程：对照两种时段的路况 → 在安全地点主动等待切换 → 经过昼夜不同的战斗区域 → 救回被困观察者。

完成与奖励：额外时段提示与终章救援助手。失败重新尝试当前路线，等待不消耗现实小时。未做此任务，主线仍能获得窗口数据并有基础撤离路线。

### S12 一册两种笔迹

触发：P5 完成主线时间观测后，在书中发现新旧记录的矛盾。

流程：复核三个主线必经地区的记录 → 区分过时观察、遗漏和误判 → 写下校订依据 → 与持不同观点的人核对。

完成与奖励：校订页、已有结局的额外对白和物种补漏提示。三个证据都来自主线可访问记录，不要求先完成 S01～S11，也不要求图鉴全满。校订不改变主线已验证的安全归途条件。

## 4. 全收集规则

新增成长系统见 [战斗、异兽能力与装备](shanhai-combat-progression.md)。图鉴完整收录、异兽能力解锁和装备/服装收集分别统计；图鉴不要求挑战所有生灵，能力则由对应挑战胜利获得。隐藏异兽线索可接入 S04/S06/S09 等地区调查，但具体事件尚待设计，不将支线结算等同击败。原异兽数量与全收集时长均须结合新增能力/装备清单重估，不能宣称现有预算已覆盖全部新增内容。

首轮建议内容预算为 60 个独立物种条目：28 植物、20 普通动物、12 异兽，数量为提案，须按样段成本复核。外观换色、幼体和季节形态原则上属于同一条目，不靠换皮填数量；其中现实物种与古籍、原创物种分开标注来源。每个物种的具体名录在下一轮物种设计中编写，不把尚不存在的名单视为已完成资产。

每条目分“发现、了解、完整收录”。发现记外形与地点；了解记录行为或用途；完整收录完成一到两个该物种有辨识度的观察条件。各条目展示清晰的未完成条件，线索可以保留发现乐趣，但不能只写“？？？”让玩家全图盲扫。

| 类别 | 合理条件 | 不采用的强制条件 |
| --- | --- | --- |
| 植物 | 辨识、可再生采样、观察开花或生境 | 拔光稀有种群、现实季节等待 |
| 普通动物 | 足迹、取食、栖息或迁徙观察 | 每种都击杀、捕获或饲养 |
| 攻击性异兽 | 观察预警动作、战斗接触或剧情调查 | 刷固定击杀次数、低概率掉落唯一资料 |
| 唯一剧情生灵 | 固定事件、主线痕迹记录 | 错过一瞬演出就永久缺条目 |

观察在规定地点可重复触发；无现实昼夜、联网日历或随机稀有刷新门槛。进入终章前未发现的物种继续在探索存档可获得；剧情改变栖息地时提供明确迁移提示与备用地点。

采集样本与收录状态分离：交付、出售或制作消耗样本不降低已收录进度。尚未设计捕捉、饲养、种植经营系统，不默认全收集包含这些系统。地区完成度显示可发现总数、已发现和已完整条目；主线关键调查另栏显示，不能与全收集百分比混淆。

## 5. 与多线结局的关系

- E1 归乡、E2 守山、E3 封隙、E4 强渡的基础机会均由主线提供。
- S03/S11 可改善终章补给与救援；它们降低局部困难但不跳过主线必需证据，也不让未完成者被迫进入强渡。
- S05/S07/S09 改变地区和人物后日谈；S06/S08/S12 改变前任对谈、信件与记录。每个任务结果最多控制有限的场景或对白变体。
- 全收集奖励完整万物志和额外注释，不独占“真结局”，不抹去强渡等路线已经造成的后果。
- 玩家可以拒绝支线；没有隐藏任务超时和永久图鉴损失。故事上无法重演的事件通过保留的现场记录提供等价收录渠道，但不能伪造玩家已经帮助过某人。

## 6. 剧情系统数据要求（后续实现契约）

任务状态为未发现、已发现、进行中、待回访、完成；临时失败返回可重试步骤，永久的人物选择单独保存。每条任务具备稳定 ID、触发条件、步骤、证据、完成条件、结果与奖励标志。不能从当前对白文字推导剧情状态。

需要记录：主线章节和节点、证据集合、独立图鉴条目与观察位、支线步骤与结果、NPC 位置阶段、世界局部变化、已经发放的奖励、终章路线与结局记录。

流程原则：

- 先发现证据再接任务时，应识别已有记录并推进适当步骤；不要强制重新调查同一物件。
- 奖励发放一次；重复对话或读档不能重发。存档要一起保存任务进度、关键物品与已发奖标志。
- NPC 搬迁、死亡或剧情离开时提供事先定义的替代交付与记录渠道。替代渠道更新信息，不默认修改人物命运。
- 场景变化由明确阶段控制，读档直接恢复；战斗死亡只回退当前可重试过程，不清空永久收录。
- 终章前自动保留开放探索快照，路线锁定前另存分支快照；不能覆盖玩家唯一的自由探索存档。
- 任务在存档中的版本迁移、旧存档支持范围需在实现时设计；本次文档不声称已有兼容系统。

## 7. 后续试玩验收

1. 不做任何支线、不完成总图鉴，也能走完主线并知情选择结局。
2. S01、S02 与序章主线交错进行，顺序互换、重复调查和读档均不失去状态。
3. NPC 移动后仍可完成相关任务，采样耗尽后有明确补充路径。
4. 昼夜与开花观察可主动推进，无现实时间等待或随机刷新阻塞。
5. 四条结局分别检查条件、分支快照、行动后果与尾声；非法状态不会误入另一线。
6. 通关后可用明确标注的探索存档补齐全部物种，奖励不会重复，剧情结果不会串档。

这些是未来游戏实现的验收要求，本轮只完成设计文档，尚未执行运行测试。
