# 山海录：战斗、异兽能力与装备成长

版本：0.1（系统设计讨论稿） · 2026-09-07<br>
关联：[主线](shanhai-story.md) · [世界观](shanhai-world.md) · [支线与收集](shanhai-side-quests.md) · [美术](art-direction.md) · [玩法整合与参考](shanhai-gameplay.md)

## 1. 已确认要求与待定细节

已确认：探索与即时战斗；每章都有异兽，包含强大、恶意、善意以及与人共同生活的个体；有隐藏异兽；击败异兽可获得它的能力；游戏包含装备和服装。

新增已确认：异兽的力量可以化作玩家的武器或护具，统称“铠化”。采用力量显化，不是把异兽本体变成装备、收进背包或消耗其生命。

首个来源已确认：狌狌通过自愿试炼授予“轻足”，显化小腿与足部护具，支持战斗短距离移步与指定窄沟、断路跨越。胜利不要求击杀或食用，本体仍可交往；具体数值与槽位规则仍为提案，详见 [玩法整合第 3 节](shanhai-gameplay.md#3-主角最初如何战斗)。

以下为落实这些要求的建议规则，不代表数值已经定案：首次按能力来源解锁、非致死切磋、有限技能装配、固定特色装备、整套服装、外观与属性分离。武器类型、槽位数量、冷却/精力机制、升级材料、失败惩罚与完整能力表仍待讨论。本文件只定义设计，没有实现游戏系统。

讨论基线补充：新的 [玩法整合提案](shanhai-gameplay.md) 第 3～7 节为上述待定项提供可测试的推荐方案，包括初始短矛、两个主动槽、重击/闪避精力、持续铠化形态与技能冷却、两个器物槽、死亡保留成长。以下保留系统边界；涉及具体配置与失败方案时以该提案为当前讨论基线，仍不视为用户已确认。

## 2. 核心循环

探索发现线索 → 观察并认识异兽 → 选择避让、交往或挑战 → 挑战胜利获得能力 → 搭配武器、服装与器物 → 尝试新的战斗方法或进入额外探索空间。

观察提供行为知识；战斗技巧来自练习；异兽能力与装备提供打法选择。不能把角色成长全部归结为等级数字，也不让图鉴解锁前的敌人免疫伤害。

## 3. 异兽身份与挑战规则

| 关系 | 在世界中的行为 | 能力获得方式建议 |
| --- | --- | --- |
| 共生 | 与人生活，参与驮运、警戒、寻水等活动，有自身需求 | 自愿切磋或认可试炼胜利，不要求伤害村落伙伴 |
| 善意 | 主动救助或保护，有自己的原则 | 完成其主持的挑战，得到认可 |
| 中立/领地性 | 警戒、护幼、捕食或守护领地 | 可避让；选择挑战并降服、驱退后获得能力 |
| 恶意 | 有意识地欺骗、诱猎或伤害其他生命 | 调查与追踪后击败，具体死亡或逃离由剧情决定 |

强弱与善恶分别设计，不能用战力或物种外形直接判定立场。同种异兽可以有不同个体经历。《山海录》记录物种习性与重要个体，不直接提供全知善恶标签。

每个可击败的异兽都须有明确的能力奖励映射，不只首领掉能力。建议同一能力来源首次胜利解锁，重复胜利不叠加同名能力；普通同种个体共享来源 ID，具备独有能力的重要个体使用独立来源 ID。材料奖励与能力奖励分开。

降服、驱退和试炼必须有清楚的胜利事件；随意碰一下或使动物脱离视野不算击败。不可挑战的剧情存在可以仅供观察收录，不强行改成可击杀目标；每个物种需标明是否可挑战。单纯观察或投喂不能替代已定义的能力挑战。

友好挑战开始前告知规则，有投降或终止机制，胜利不把对方永久变成敌人。恶意攻击友方不能成为获取同一奖励的捷径；是否允许这种攻击是后续交互规则选择。

## 4. 基础战斗与能力装配

建议第一版保留普通攻击、重攻击、闪避、少量主动能力与快捷药物。格挡、弹反、跳跃攻击尚未确认，不同时扩展全部动作体系。

武器决定普攻/重击、距离和动作；异兽能力提供突进、牵制、感知、防护等特殊行为。具体例子是能力职能，并非已确定物种或原典功效。每个能力都要定义发动预警、作用范围、消耗或冷却、被打断规则和探索用途。

建议永久收集、有限装配，在安全且脱离战斗时调整，原型先测试两个主动能力槽；快捷键待验证。能力不因死亡消失。战斗辅助瞄准要适配固定斜俯视镜头，键鼠与手柄分别验证，不照搬自由第三人称锁定。

探索能力与地图依赖明确：主线必要通行能力在必经挑战获得；隐藏能力用于额外路线、可选宝藏和打法。禁止隐藏能力在自己才能到达的位置，禁止让友方被剧情移走后必要能力永久不可得。允许未装备时在安全地点调整或提供可达休息点，不让玩家进入不可返回的能力死路。

## 4A. 力量铠化

挑战成功后，玩家取得异兽力量的使用资格，显化为武器或护具。建议由《山海录》保存“力量印记”并承载铠化；书的具体承载表现仍为提案。力量印记与归途剧情中的“来处印记”是不同概念，获得异兽力量不会改变玩家的故乡或自动开启归途。

| 形式 | 表现与职能 |
| --- | --- |
| 武器铠化 | 将异兽特征转译为武器形态与攻击方式，不把整只异兽缩小后握在手里 |
| 护具铠化 | 显化为护具或附着于服装的结构，体现防护、机动或特殊适应能力 |
| 异兽技能 | 运用同一力量的主动或被动效果，不必每次都切换整套装备 |

每个能力来源需要明确奖励是技能、武器铠化、护具铠化或其组合；“每次首次击败有对应能力”不等于每种异兽必须生产三套奖励。隐藏异兽也遵循这套映射。

本体与力量分离：铠化不是召唤本体或灵魂囚禁。友好异兽在挑战后仍可生活与交互，敌对异兽的生死由具体事件决定，能力奖励不要求追加击杀。建议解锁后不依赖本体跟随、存活或实时距离，避免剧情迁移使装备失效。

与普通装备共存的建议：普通武器和服装提供基础动作与属性；启用武器铠化时替换对应武器的有效形态与规则，护具铠化占用明确的护具力量配置。不要将两套完整基础属性无条件相加。关闭或无法发动时仍有可用基础装备。具体是持续装备形态还是有时限的战斗状态、可否同时启用武器与护具铠化、消耗与冷却、切换地点均待测试讨论，不先定死。

模型沿用东方山海气质，以角、羽、鳞、甲、骨架节律等可辨识特征转译为原创器形，保留适当材料质感；不默认现代机械装甲、全身发光或完整兽形变身。战斗时铠化形态需要可辨，外观自由搭配不能隐藏攻击距离与生效状态。具体物种与能力对应需单独设计，不冒称原典本就记载了该铠化能力。

后续数据须区分来源解锁、可用铠化形态、当前配置、临时发动状态及普通装备。保存永久解锁，读档时按规则恢复或结束临时状态；解除铠化不得删除基础装备、遗留属性加成或重复授予技能。

## 5. 隐藏异兽

通过当地传闻、特殊足迹、异常植物分布或环境现象留下可理解的线索。建议形成“听闻/发现痕迹 → 验证活动条件 → 找到栖息地 → 挑战 → 获得能力”的短链，不要求现实时间等待、随机极低概率刷新或无提示摸墙。

隐藏异兽的能力要有独特用法，而非全部比主线奖励更强。隐藏挑战可以困难，但失败可重试；首次胜利奖励确定获得。唯一个体的奖励直接绑定胜利记录，不使用可能掉进地形或被遗漏的唯一掉落物。

每章是否有隐藏异兽及总数量仍待预算，不把“每章有异兽”自动扩大为每章强制新增隐藏首领。既有 12 异兽物种预算是旧建议，需要结合能力数量重估，不靠换色扩充奖励表。

## 6. 装备、服装与外观

| 装备类别 | 职能 | 建议来源 |
| --- | --- | --- |
| 武器 | 动作、攻击距离、招式风格 | 主线、探索、制作、交易 |
| 服装/护具 | 外观、防护、环境适应 | 聚落工艺、任务、材料升级 |
| 饰物/器物 | 有限的被动效果或打法变化 | 支线、遗迹、隐藏探索 |
| 异兽能力 | 特殊战斗与探索动作 | 对应挑战胜利 |

建议固定设计、明确长短处、有限升级，不以随机词条与稀有度刷取延长主线。升级不应反复要求击杀已经完成图鉴的稀有生灵；材料与升级量待验证。

服装建议按整套制作，武器和饰物独立装备，减少模型组合与穿模成本；不默认头、胸、手、腿分别替换。获得服装后可考虑外观与属性分开选，且战斗能力状态提示不依赖所穿外观。环境适应效果不等于已决定做复杂寒冷/饥饿生存系统。

当地装备沿用上古聚落材料语言：麻布、毡、皮革及土木竹藤陶工艺，少量金属与玉石用于有来历的物件。具体材料和工艺仍需地域考据。主角现代来处已定，初始服装应符合其尚未确定的具体身份；后续获得当地服装，不把现代初装语言扩散到聚落居民装备。

## 7. 章节整合建议

每章至少有一个有剧情或生态职能的重点异兽，同时允许旧物种再次出现，不要求每章把所有善恶类型都凑齐。

| 章节 | 异兽与成长承担的内容（提案） |
| --- | --- |
| P0 | 先以枯枝防身并学习短矛，再用基础动作通过狌狌试炼，取得第一力量与腿足护具铠化“轻足”；目标前 45 分钟取得首个力量，全部计入序章 2 小时 |
| P1 | 迁徙与领地挑战，教学如何搭配能力；通过支线发现隐藏栖息地线索 |
| P2 | 有智慧、不同立场个体的事件；展示非致死试炼，不把所有九尾狐都写成相同立场 |
| P3 | 强大生灵与建木关系，挑战支撑调查；器物升级服务既有打法 |
| P4 | 善意生灵与地方恢复；可选隐藏挑战提供新打法，凤凰仍可只作剧情存在 |
| P5 | 在时段变化中组合运用已有能力；获得主线必要观察条件，不强制击败烛阴 |
| P6 | 各路线检验已学技巧与搭配，既有异兽可敌对或协助，不以全能力收集判定结局 |
| P7 | 收尾呈现人与异兽关系结果，不为半小时尾声硬加一场能力战 |

## 8. 与图鉴、支线、结局的边界

分别记录“发现/完整收录”“挑战胜利/能力解锁”“装备拥有/升级/外观”。看全图鉴不要求攻击所有生灵，解锁全部可获能力需要完成对应挑战；二者可以有独立进度与奖励。

既有支线可提供试炼或隐藏线索，但不把整条任务完成直接当作战斗胜利。新隐藏链优先复用地区与角色，纳入可选探索时间，不能在现有 30 小时主线、10 小时支线和全收集预算上重复计时。

四结局基本机会由主线保证。装备品质、异兽击杀总数、能力收集率不暗中决定“好坏结局”；具体攻击/保护重要个体可以产生明确的地方或人物后果。是否所有可挑战友善个体的试炼都可在结局前补做，需要逐一检查。

## 9. 后续实现与验收要求

- 能力奖励、首次胜利和挑战结果一并保存，使用稳定来源 ID；重复事件和读档不重发，胜利后死亡也不会出现已胜利但缺能力的状态。
- 图鉴、能力、装备与外观分别存储；样本消耗、出售普通材料不影响永久解锁。旧存档迁移单独设计。
- 友好试炼失败恢复友好状态，胜利后保留角色可交互；重要 NPC 离开前保证必要奖励渠道。
- 检查每个可击败异兽有能力映射、隐藏奖励非随机、没有能力依赖循环，基础路线不要求隐藏装备。
- 检查服装更换时模型、动画、碰撞和属性一致；外观切换不重复加属性。
- 验证能力在战斗与探索中的限制，不能通过突进穿越剧情边界或跳过必要存档状态。
- 首个样段验证一套武器、少量敌人、一次能力获取和装配、一次友好试炼、一次装备更换与存档重载，再评估完整物种与装备数量。

以上均为未来游戏验收项，本轮文档更新未实现或测试这些功能。
