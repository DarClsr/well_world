## 1. 规范效力

本文件是项目当前的题材与美术方向依据，适用于新序章、环境、角色、器物、特效、UI 和资源筛选。规划笔记、旧截图、测试参数和已制作资源不构成与本文件并列的美术标准。

旧版规范见 [v0.9 历史归档](archive/art-direction-v0.9.md)。其低多边形绘本定位、固定灰绿色板、卡通角色比例、西式旅行装束、自由旋转镜头相关要求和旧序章路线不再约束新版本。本次文档更新不表示地图、模型或运行代码已经完成相应改造。

## 2. 核心定位

> 一个以好奇心驱动探索、以异兽战斗带来挑战的东方山海经异世界，采用固定斜俯视、偏写实的风格化 3D。

| 项目 | 已确定方向 |
| --- | --- |
| 题材 | 东方山海经风格的原创异世界 |
| 世界构成 | 山川、异兽、奇木异草与人类聚落 |
| 核心玩法 | 探索与即时战斗相互推动 |
| 主情绪 | 好奇、想探索，逐渐加入神秘、敬畏与危险 |
| 美术表现 | 偏写实的风格化 3D |
| 镜头 | 固定斜俯视、有限缩放，暂不自由旋转 |

山海经题材通过生态、地貌、物种及其与生活的关系体现。古籍与古代器物提供创作依据，游戏中的组合、能力和世界规则属于原创设计，不应表述为考古或历史定论。

## 3. 美术表现

### 造型与材质

- 比例、结构、生长方式和材料表现可信，保留清楚的轮廓与适度概括。
- 写实程度服务于实际斜俯视观看距离，不以贴脸观察或电影级细节为制作目标。
- 木纹、石面、织物、陶器与金属应体现各自的材质特征；磨损和色差有结构依据。
- 使用基础色、粗糙度、法线等材质信息建立质感；不以噪点、污渍或夸张斑驳代替写实。
- 角色与环境采用一致的写实程度。主角身份、服装、具体头身比例尚未确定，不继承旧版的固定卡通比例。

### 自然环境与神异元素

- 以中国山野为自然基础，神异融入生态、尺度和生长结构。
- 植被分布、岩石结构、水流和地形关系应可信，同时允许原创物种与非寻常尺度。
- 异兽和奇木异草应能支撑观察、探索或战斗，而不只是背景装饰。
- 神异事物不统一使用自发光或青色符文；通过形态、运动、声音和环境关系建立辨识度。

### 建筑与器物

已确认力量铠化：异兽力量显化为武器或护具，本体不变为装备。视觉需保留对应异兽的辨识特征并符合东方山海风格，避免默认机械装甲或全身高亮特效；形态与消耗方案仍待讨论。

装备与服装已纳入成长系统，美术需支持可识别的武器、服装外观变化与器物。整套服装和外观/属性分离属于当前提案，详见 [战斗与成长设计](shanhai-combat-progression.md)。异兽既有敌对者也有友善与共生个体，造型与行为不能全部按敌人设计。

- 日常材料以土、石、木、竹、藤、麻、陶为基础。
- 青铜、玉石和特定纹样用于有文化依据的祭祀、身份或地域场景。
- 建筑与用品体现生活用途、制作方式和使用痕迹。
- 具体年代、地域与文化借鉴尚未确定，不预先锁定某一朝代、聚落形式或建筑样式。

### 色彩与光影

- 自然色为底，允许随地域、季节和生态变化，不锁死灰绿或鼠尾草绿。
- 局部鲜明色彩用于突出神异事物、交互目标和重要视觉线索。
- 材料的粗糙度、透光和反射差异应在游戏灯光下成立。
- 日光、火光、雾与空气透视用于建立空间层次；避免全屏浓雾或强泛光遮掉细节。
- 好奇与探索是序章的主要情绪，危险感逐步显露，不默认整张地图阴暗、恐怖或压抑。

## 4. 镜头与玩法可读性

- 采用 3D 场景和固定斜俯视镜头，支持有限缩放，暂不自由旋转。
- 具体倾角、投影方式、跟随参数和缩放范围待灰盒验证，不在此阶段固定数值。
- 资源精度与地图展示范围围绕实际镜头设计，优先投入看得见的轮廓、材质和动作。
- 路径、高差、入口、交互目标、敌人动作和攻击范围必须容易判断。
- 树冠、屋顶等遮挡需要处理，避免挡住玩家、敌人或战斗反馈；具体淡出或隐藏方式待验证。
- 战斗区域保留可读的地面与移动空间。探索与即时战斗均是核心体验，不能继续沿用旧版“战斗不是视觉核心”的限制。
- 《Death's Door》和《TUNIC》仅作为斜俯视构图、空间组织与可读性的参考，不作为卡通比例、材质或文化造型的直接标准。

## 5. 资源制作与验收

- 每件可复用资源独立保存，统一尺度、原点、命名与材质表现。
- 动画、碰撞与物理行为按用途制作并明确标注；有模型不等于已有拾取、装备、破坏等玩法。
- Blender 用于制作，最终视觉验收以 Godot 实际游戏镜头、灯光和环境下的截图及运行效果为准。
- 资源按大类或完整区域验收，同时检查场景内的一致性；不单凭独立模型渲染判断合格。
- 既有树木、植物、杂物和器物先留存，按新规范重新筛选；此前验收通过不等于自动适用于新方向。
- 不固定现成资产与原创资产的比例。外部资源应检查授权、风格适配及实际运行成本。

## 6. 风格边界

明确避免：

- 幼态卡通、玩具般圆润造型和统一平涂色块。
- 把东方题材简化为通用仙侠式发光装饰或任意堆砌纹样。
- 未经统一处理混用西式奇幻器物、卡通角色和写实环境。
- 用密集噪点、过度做旧或斑驳掩盖结构问题。
- 为自由近景观看制作大量在固定镜头下不可见的细节。
- 直接复制参考游戏的角色、建筑、地标、符号或 UI。

## 7. 新序章范围与待定事项

序章地图从零设计，旧版保留，不以旧地图的路线、建筑或剧情节点作为新地图的默认约束。先讨论确定美术方向板、序章构想与地图草图，验收后再进入灰盒和完整美术样板制作。

以下内容尚未定案：

- 序章已确定开阔、苍劲的北方山野与朴素的上古聚落；具体开场地点、季节和路线仍待定。异兽参与生态、探索、战斗和收集，首批设计观察型、基础战斗型及强大生灵踪迹，具体物种待选。世界观深化见 [山野、众生与归途](shanhai-world.md)。
- 具体年代、地域、建筑文化与纹样体系。
- 主角具体身份、造型、初始现代服装及装备；现代来处和穿越后废墟拾书已定。
- 战斗手感、武器、技能、敌人配置与难度。
- 序章路线、时长、剧情节点及结尾。
- UI 的具体视觉语言。

穿越后在废墟拾书已确认为开场事件。废墟作为旧行旅观察所、具体醒来位置、特殊植物与远处移动山脊等仍是构想示例；不由拾书设定扩大为大型地宫或整张阴暗地图。
