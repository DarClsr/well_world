# 《异世界漫游记》美术风格规范

版本：0.6<br>
日期：2026-09-02<br>
适用范围：序章纵切片及后续环境、角色、特效、UI 和素材筛选

规范效力：本文件的最新版本是唯一美术权威；`task_plan.md`、`findings.md`、`progress.md` 和历史阶段参数只记录当时的实现与验证，不作为后续验收标准。已验证画面暴露出冲突时，应同步修订本规范、测试契约和固定证据，不能为了保留旧参数牺牲当前成片质量。

## 1. 核心定位

《异世界漫游记》采用**精品风格化 3D**：以《Death's Door》的俯视舞台感、轮廓概括和角色可读性为主要参考，不追求照片级写实，也不做幼儿卡通，而是塑造一本可以走进去的奇幻旅行绘本。

核心体验是：

> 初到陌生世界的孤独感，村庄带来的短暂温暖，以及浓雾之外持续存在的未知。

一句话美术定义：

> 低多边形绘本式奇幻 3D，以鼠尾草绿、赭石和青色魔法光构成冷暖层次，强调漂泊、村庄温度与迷雾未知感。

## 2. 风格支柱

### 2.1 绘本式世界

- 场景像经过构图的立体插画，而不是写实自然环境。
- 造型使用清晰的大轮廓和适度夸张的比例。
- 材质保留手绘色块、柔和渐变和少量可控笔触。
- 每个可见画面都应有前景、中景、远景和明确视觉焦点。

### 2.2 温暖与未知并存

- 村庄、炉火、窗户和友好 NPC 使用暖色光。
- 传送门、遗迹、异界植物和剧情异常使用冷青色光。
- 山口、谷边和未知区域使用蓝灰、灰紫及低对比度迷雾。
- 安全区域不能过于明亮欢乐，危险区域也不能变成纯粹黑暗恐怖。

### 2.3 清晰的俯视探索

- 道路、入口、交互物和危险边界必须在俯视镜头下清楚可辨。
- 角色轮廓不能被地面、屋顶或植被吞没。
- 高饱和度按视觉层级使用：叙事焦点可以最强，环境中允许少量季节性或地域性色彩作为次级点缀。
- 装饰不能破坏通行判断，场景丰富度服从玩法可读性。

### 2.4 克制的精品感

- 用少量高质量焦点代替无意义的道具堆积。
- 同一画面最多设置一个主焦点和一至两个次焦点。
- 特效、Bloom、雾和动态光必须有明确叙事作用。
- 资产数量不是质量指标，一致性和完成度优先。

## 3. 造型语言

### 建筑

- 房屋屋顶略高，门窗略大，强化温暖童话感和俯视辨识度。
- 木梁、石基和屋瓦采用大块结构，不依赖细碎表面纹理。
- 建筑轮廓允许轻微不对称、倾斜和生活磨损，避免标准模型盒子感。
- 重要建筑通过轮廓、光色和周边活动区区分，而不是只靠招牌。
- 屋顶在常规状态保持完整不透明；只有建筑实际进入相机到玩家或室内活动主体的视线遮挡带时，才平滑退至完全隐藏，离开遮挡带后平滑恢复。单纯靠近房屋、站在门前、炉火旁或房屋侧面不得触发切顶。禁止把多层瓦片、梁架或山墙长期停在半透明端态，以免产生叠层鬼影。
- 同一栋房屋的屋瓦、梁架和烟囱必须共享一个切顶状态；进入与退出遮挡带使用小幅迟滞，玩家沿边界移动、贴墙滑动或短暂停步时不得反复闪现。镜头提前量应随真实移动速度连续变化，不能把微小碰撞速度放大为满额偏移。
- 切顶只解决镜头遮挡，不得同步隐藏墙壳、室内地面、家具、门窗或碰撞；玩家位置和房屋边界必须仍然可信。

### 自然环境

- 岩石使用清楚的大切面，避免高频噪点和照片扫描感。
- 树冠成块、树干适度扭曲，形成绘本剪影。
- 植被按簇布置，疏密有节奏，不能均匀铺满地面。
- “疏密有节奏”不等于减少整张地图的草量；已经成立的草甸体量应优先通过活动区硬排除、密度重分配及高度或形态变化维持节奏。只有通行可读性、角色遮挡或性能证据明确不合格时，才减少总量。
- 道路自然弯曲，并通过磨损、石块和植被缺口引导方向。

### 魔法与遗迹

- 异界石环采用破损石构、圆形符文和青白微光。
- 魔法造型应古老、安静、难以解释，避免科幻机械结构。
- 符文、漂浮微粒和空间扭曲保持稀疏，避免廉价粒子喷泉感。

## 4. 色彩规范

| 内容 | 主色方向 | 作用 |
| --- | --- | --- |
| 雾谷自然环境 | 鼠尾草绿、灰绿 | 安静、陌生、承托主体 |
| 季节性环境点缀 | 酒红、旧金、灰紫 | 丰富区域记忆，保持次级层次 |
| 土路与建筑 | 赭石、陶土红、木棕 | 生活痕迹与温度 |
| 村庄炉火 | 琥珀橙、柔和金色 | 安全、停留、人物关系 |
| 异界石环 | 青白、低饱和蓝 | 魔法、来处、未知联系 |
| 浓雾山口 | 蓝灰、灰紫 | 危险、远方、下一章节 |
| 主角旅行装束 | 深绿、旧皮革棕、少量暖色 | 漂泊感并保持环境可读性 |

规则：

- 大面积环境保持中低饱和度。
- 冷青与暖橙是核心叙事对比；环境点缀可以局部偏鲜艳，但面积、明度对比和饱和度不得同时达到叙事焦点的强度。
- 环境高彩点缀不使用自发光或 Bloom，同一常规镜头中控制为一至三处小面积色块，并在昼夜与天气变化下保持次级。
- 色彩是否过强以实际构图中的注意力顺序判断，不用固定颜色白名单替代成片审核。
- 每个区域建立有限色板；新增素材必须先调色再进入正式场景。
- 避免纯黑阴影、纯白高光和未经控制的彩虹渐变。

## 5. 材质规范

- 整体使用哑光或半哑光表面，减少塑料感和过强镜面反射。
- 木材、石材、泥土使用简化手绘纹理和大尺度色差。
- 地面至少包含基础色、柔和明暗层、道路磨损和局部生活痕迹。
- 法线与粗糙度用于增强大结构，不能制造密集视觉噪点。
- 来自不同素材包的模型必须统一色相、明度、粗糙度和纹理密度。
- 写实扫描材质不能直接与低多边形角色和建筑混用。

## 6. 灯光、雾与镜头

- 基础日光柔和，阴影边界清楚但不过黑。
- 村庄通过炉火、窗光和暖色反弹形成局部安全岛。
- 魔法遗迹通过冷青边缘光和低强度地面辉光成为远距离地标。
- 雾分为近景漂雾、中景空气透视和远景遮蔽三层。
- Bloom 仅用于魔法与炉火，不能覆盖物体轮廓。
- 俯视镜头维持稳定构图；地形、树木和建筑共同形成视线框架。
- 镜头旋转后，各主要方向仍必须存在可识别地标。

## 7. 角色规范

### 通用角色语言

- 玩家采用约 4～5 头身的紧凑比例，NPC 可在 4.5～6 头身内变化；整体比写实人物更短、更宽、更容易从俯视角识别。
- 头部、帽檐、披风、武器和职业道具构成角色的主要轮廓，手指、五官和服装缝线不是优先细节。
- 面部表情保持极简，情绪主要通过头部角度、身体重心、停顿和动作节奏表达。
- 每名重要角色只使用两至三个主色块，并用一个小面积高亮色表示身份或剧情关系。
- 角色材质采用柔和卡通明暗，与环境的自然光照形成轻微但稳定的视觉分离。
- NPC 通过职业轮廓、配色和道具区分，不依赖头顶文字。
- 动画数量可以克制，但 Idle、Walk、Run、转身和交互过渡必须顺滑、明确且略带弹性。

### 玩家“漂泊者”

玩家不能只是常规写实比例的游侠模型。最终造型需要像《Death's Door》的乌鸦主角一样，在很小的屏幕占比下仍能一眼认出，但不能复制乌鸦、收割者或其具体服装。

固定视觉要素：

- 略大的头部轮廓，以及帽兜或旅行帽形成的明确顶部形状。
- 短斗篷或不对称披肩，在移动和转向时提供方向感。
- 小型旧背包，强化“从别处来到这里”的旅行身份。
- 一件短武器、手杖或工具，长度不能破坏紧凑轮廓。
- 深森林绿为主体，旧皮革棕为次色，围巾内衬或布条使用克制暖色。
- 与异界石环呼应的一处青色微光标记，作为主角与世界谜团的联系。

俯视识别要求：

- 纯黑剪影下仍能区分头部、斗篷、背包和手持物。
- 角色站在草地、土路、石地和暖色炉火旁都不能丢失轮廓。
- Idle、行走、奔跑和交互四种状态只看姿态就能辨认。
- 转向时披风和配件提供视觉惯性，但不能遮挡碰撞和移动判断。

现有 Quaternius Ranger 可继续作为移动、碰撞和动画验证资产，但其比例与通用 RPG 外观不足以承担最终主角辨识度。正式纵切片应当对其进行明显改造，或替换为更符合上述轮廓规则的角色。

## 8. 特效与 UI

### 特效

- 魔法特效以符文、微光、薄雾、尘粒和轻微空间变形为主。
- 炉火强调温度、节奏和周围受光，不依赖大量火星。
- 交互反馈应短促、明确、可分级，重要剧情反馈强于普通移动反馈。

### UI

- UI 使用旅行手记、羊皮纸、墨线和地图标记的视觉语言。
- 正文使用清晰现代字体，装饰字体只用于标题和地点名。
- 面板保持轻薄，避免大面积遮挡场景。
- 图标采用统一线宽、有限色板和清晰轮廓。

## 9. 素材策略

采用“优质现成资产打底 + 深度统一改造 + 原创核心资产”的组合方式：

- 约 60%：树木、岩石、普通道具、基础建筑模块和通用动画等优质现成资产。
- 约 25%：统一材质、调色、比例、组合和轮廓后的改造资产。
- 约 15%：主角、异界石环、章节地标、核心特效、UI 等原创资产。

现有 Quaternius 资产可作为基础造型库，但不能未经处理直接视为最终美术。所有入选素材至少经过一次比例、材质、颜色和场景关系复核。

### 素材准入检查

候选素材只有同时满足以下条件才进入正式版本：

- 轮廓在当前俯视距离下清楚。
- 造型可以归入绘本式低多边形语言。
- 材质能够调整为哑光、低噪点和有限色板。
- 比例可与现有人物、建筑和道路统一。
- 许可证明确允许目标商业用途。
- 不会成为一眼可辨的“素材包主角”。

## 10. 参考游戏与借鉴边界

### [TUNIC](https://tunicgame.com/)

最接近本项目的俯视探索表达。重点参考：

- 俯视场景的道路、入口和地标可读性。
- 小比例角色与大环境之间的关系。
- 简化造型、有限色板和神秘遗迹表达。
- 像立体模型一样干净的场景构图。

不直接照搬狐狸主角、符号系统、战斗表现和具体建筑设计。

### [Death's Door](https://playdeathsdoor.com/)

这是本项目的主要风格参考。官方制作名单显示 Frits Olsen 负责美术指导、概念、UI 与标志设计；开发访谈则将其画面概括为自然光环境与轻量卡通着色角色的并置。开发者也明确谈到，可爱的卡通乌鸦与黑暗死亡主题之间的反差是角色成立的重要原因。参考资料：[官方制作名单](https://www.acidnerve.com/game-credits)、[Devolver 游戏页](https://www.devolverdigital.com/games/deaths-door)、[角色动画访谈](https://www.gamedeveloper.com/art/animation-feature)、[开发者访谈](https://www.nme.com/features/acid-nerve-developers-david-fenn-and-mark-foster-on-making-deaths-door-3203321)。

#### 场景风格拆解

- **俯视舞台感：** 地图像一组经过构图的小型立体舞台。围墙、树木、悬崖和建筑既是世界物体，也是画面边框。
- **大形优先：** 先用地块、台阶、道路、建筑体块和树冠建立清楚轮廓，再添加少量道具；不会依靠密集贴图制造复杂度。
- **自然光环境：** 环境保留柔和自然光和明确投影，使低复杂度模型仍有空间体积；角色则通过较简洁的明暗保持可读。
- **有限色板：** 每个区域由一个主色族控制，局部使用红叶、火光、魔法或角色色作为焦点。
- **材质克制：** 表面粗糙度稳定、纹理噪点少，视觉信息主要来自造型、光影和颜色，而不是照片细节。
- **层级清楚：** 地面最安静，建筑和植被提供中等细节，交互物、敌人和角色拥有最强对比。
- **区域记忆点：** 小地图不靠面积取胜，而是通过门、雕像、庭院、桥梁和色彩变化形成连续记忆点。

#### 玩家角色风格拆解

- **极简高识别：** 乌鸦主角的物种、头部、喙、披风和武器组成非常直接的剪影，小尺寸下仍然可辨。
- **紧凑比例：** 大头、小身体、较短四肢降低了写实感，也让动作在俯视镜头下更容易读懂。
- **少色块：** 主体颜色克制，不靠复杂纹理表达身份；武器、眼睛和动作承担识别信息。
- **可爱与黑暗反差：** 角色本身轻巧、可爱，世界议题却偏死亡与衰败，因此产生独特情绪，而不是单纯阴沉。
- **动作表达性：** 行走、攻击、受击和互动强调清楚的预备、动作和回收阶段；即使角色很小，也能读出力量与情绪。
- **角色和环境分层：** 轻量卡通着色、稳定轮廓和动作节奏让主角从自然光环境中持续分离。

#### 转译到《异世界漫游记》

保留：

- 俯视舞台式场景、强轮廓和有限色板。
- 紧凑比例、极简脸部、少色块和高识别玩家。
- 自然光环境与轻量卡通角色之间的层次差。
- 以局部暖光和魔法色建立视觉焦点。
- 用连续小地标代替空旷大地图。

改变：

- 将黑色死亡寓言转为“温暖村庄与未知异界”的旅行寓言。
- 将哥特墓园和办公机构感替换为山谷、旧村、遗迹和漂泊生活。
- 主角使用人形漂泊者，而不是乌鸦、死神或其他直接相似符号。
- 总体明度和自然色比《Death's Door》提高约 15%～20%，进入浓雾和遗迹区域后再逐步降低。
- 战斗不是序章的视觉核心，探索、交谈、环境反馈和异界谜团优先。

最终目标不是“复制《Death's Door》”，而是采用它的视觉组织方法：**简单模型、强轮廓、好构图、少色块、清楚动作和统一气质。**

### [Kena: Bridge of Spirits](https://www.playstation.com/en-sg/games/kena-bridge-of-spirits/)

作为自然氛围和品质上限参考，而不是直接对标制作规模。重点参考：

- 森林、村落、岩石和魔法光效的整体统一。
- 前中远景层次、空气透视和柔和阳光。
- 角色在复杂自然环境中的色彩分离。
- 环境叙事与被遗忘村庄的情绪塑造。

不追求其模型面数、动画数量和电影级资产规模。

### [The Last Campfire](https://www.nintendo.com/en-ca/store/products/the-last-campfire-switch/)

重点参考：

- 温暖、孤独并存的绘本情绪。
- 简单角色造型承载情感的方式。
- 雾、火光和自然色彩的克制组合。
- 低复杂度场景仍保持完整艺术气质的方法。

本项目保留更明确的 3D 村庄生活感和自由探索空间。

## 11. 序章纵切片目标

第一阶段只打磨一条约 10～15 分钟的完整体验：

> 异界石环苏醒 → 经过雾池 → 抵达雾谷村 → 认识村民并完成一次活动 → 炉火旁获得线索 → 前往浓雾山口。

序章必须优先完成：

- 一条构图明确、可以记住的探索路线。
- 异界石环、炉火广场、浓雾山口三个原创视觉焦点。
- 一套统一的地面、岩石、植被、建筑和角色材质。
- 一次能展示角色动画、环境反馈和剧情气氛的互动事件。
- 稳定的镜头、灯光、雾效、音频和性能表现。

## 12. 明确避免

- 多个素材包未经处理直接混用。
- 写实人物与卡通环境并置。
- 整张地图均匀铺设植被和道具。
- 依赖高饱和色、强 Bloom 或全屏浓雾制造“高级感”。
- 使用照片级地表纹理破坏绘本造型。
- 为了丰富而加入无叙事作用的建筑和装饰。
- 直接复制参考游戏的角色、地标、关卡或 UI。
- 在序章完成前扩张为开放世界。
