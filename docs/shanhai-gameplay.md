## 1. 范围与定位

在已确认的东方山海异世界、固定斜俯视偏写实 3D、探索战斗、意外穿越归家、山海录、万物收集、力量铠化、约 30 小时主线与多线结局之上，提出一套可以进入样段验证的玩法方案。新增确认（2026-09-07）：第一只试炼异兽采用狌狌，胜利获得腿足护具铠化“轻足”，用于战斗移步与指定窄沟、断路的跨越。其余数值、槽位、武器种类、路线结构和开场细节仍为提案，未获逐项确认；本文件内容尚未实现。

玩家每次远行都在解决一个具体问题：这条路通往哪里，这只异兽为什么在这里，眼前的发现能否帮助回家。短循环为发现征兆、判断路线、观察或战斗、获得知识或力量、打开新机会；长循环为聚落准备、地区调查、关键挑战、确认归途证据、前往下一地区。

## 3. 主角最初如何战斗

主角来自现代，读过普通《山海经》，穿越后在废墟拾得另一本《山海录》，此来源已确认。建议其有普通人的行动能力，没有既成的异兽力量、战斗记忆灌输或天选血统；具体职业和训练经历未定，读过古籍不等于会战斗。拾书过程与两本书的关系见 [主线第 3.4 节](shanhai-story.md#34-主角与两本书)。

| P0 内目标时间 | 玩家经历 | 已获得的能力与依据 |
| --- | --- | --- |
| 0～10 分钟 | 穿越后寻找出路，在废墟取书，再对照实物记录植物；用枯枝防身、绕开危险 | 移动、互动、取书后的首次收录、基础挥打与闪避；拾书不依赖神异能力 |
| 10～20 分钟 | 遇到采药人与聚落猎者，借得短矛并练习保持距离 | 普攻、重击、攻击后退让；猎者教学解释动作来源 |
| 20～30 分钟 | 沿失联学徒的线索前行，处理短程威胁 | 用普通武器击退小型普通野兽或完成练习，不提前设置无奖励异兽胜利 |
| 30～45 分钟 | 参与狌狌的自愿试炼，凭基础动作取胜 | 山海录记录第一个力量印记，解锁腿足护具铠化“轻足” |
| 45～60 分钟 | 在真实路段使用新能力，找到学徒，打开返回捷径 | 完成获得、装配、使用、回访的第一次循环 |

这些时间包含在现有 P0 的 2 小时预算内，不额外增加序章。首次力量目标在 45 分钟左右，允许玩家探索造成偏差；必须实测。逃生段无强制死亡，教学失败就近重来，熟练玩家可跳过重复说明。

第一只试炼异兽已确定为狌狌（读作“猩猩”）。它生活在聚落附近山坡，与猎者熟悉，偶尔帮助寻找走失的人，同时保留自己的领地与习性。首次相遇时它在高处观察主角，随后玩家通过足迹与声音再次找到它。清理通路作为取得试炼资格的具体事件仍为提案；帮助不直接授予力量，挑战胜利才解锁。

试炼采用扑进、横扫、短暂退让，让玩家用短矛与基础闪避抓住破绽。胜利条件建议为躲过攻击并在收招时命中三次，计试炼进度，不必耗尽生命；命中次数仍待试玩。失败不损害关系，胜利后狌狌仍可交往。其所有招式可用基础移动和闪避处理，轻足绝不参与试炼的入场或胜利条件。

第一力量已确定为“轻足”：力量在小腿与足部形成护具，用筋束与白色短毛等特征建立轮廓，不变成完整兽身。战斗中发动一次短距离快速移步，避开扑击或调整攻击位置；探索中跨过明确标示的窄沟或断路，打开附近捷径，不能任意飞越山崖。它区别于基础闪避的重点是主动调整位置与指定跨越用途，具体距离、冷却和是否有无敌帧仍待验证，不提前承诺无敌效果。

实现建议：轻足强化动作占一个主动槽，要求对应护具形态启用，遵循技能冷却与换装不刷新规则。战斗移步检查沿途障碍；探索跨越仅在指定起落点、落点安全且路线允许时触发，不能穿墙或跳过剧情边界。首次使用点放在安全地点，配置和冷却均不造成永久阻塞，基础归路始终可通行。

原典依据与改编边界：《山海经·南山经》招摇之山段记载狌狌白耳、伏行人走，并有“食之善走”的描述；版本文字在正式图鉴引用前校核。轻足取“善走”意象，改为自愿试炼胜利后获得力量，不要求食用、杀死或消耗狌狌。聚落关系、寻找走失者、试炼、铠化与跨沟均为游戏原创。将其放入北方山野气质的地图是原创地域重组，不宣称原典把它置于北方。

完整依赖为普通行动 → 当地教学与短矛 → 狌狌试炼 → 力量印记 → 轻足 → 可选跨沟捷径。山海录保存力量，但不代打；首次胜利后狌狌仍在聚落附近生活。原“镇步”退出首次奖励方案，仅保留为后续厚甲、力量型异兽的候选能力，具体来源尚未确定。

## 4. 战斗操作与铠化基线

建议原型采用普通攻击、重击、闪避、两个主动能力与一个快捷恢复物。格挡与弹反先留作后续选项，首战不以它们为必需动作。键鼠按指向攻击，手柄按摇杆方向配温和辅助瞄准；辅助选择可见且在有效范围内的目标，不能隔墙吸附。

- 生命负责承受错误。精力约束重击和连续闪避，普通轻击不消耗精力；停用消耗动作后自动恢复。非战斗移动不耗精力，精力耗尽仍能走动和轻击。
- 铠化配置为一个力量来源，可选该来源已有的武器形态或护具形态；第一版不同时开两套形态。形态持续生效，强化动作使用独立冷却，不另加第三条能量条。
- 两个主动槽可以搭配已解锁技能，其中需要当前铠化形态的动作只在相应配置有效；配置界面直接标明，禁止装备一个永远不能发动的组合。并非每个来源都必须有形态和主动技能。
- 在安全且脱离战斗时调整能力与铠化，调整期间禁止移动攻击；主线关键能力首次获得现场即可配置。换装保留原技能剩余冷却，不能通过切换刷新。
- 武器铠化采用对应形态自己的动作与基础参数；普通武器保留在背包，解除时恢复。护具铠化叠加明确的专属效果，不再复制一套全身防具属性。
- 回血使用有限次数的药囊，在已激活休息点免费补满基础次数；消耗品作为额外准备，主线不靠反复采药才能重试。

普通武器贯穿全程可用，主线敌人没有“未装某隐藏力量就完全免疫”的限制。铠化的价值是新动作与应对方法；不同属性可以影响效率，但主线不建立大量硬性克制锁。

敌人以预警、出招、收招窗口形成节奏。首次单独展示一种招式，之后以组合与地形增加难度；首领变化应改变玩家应对，不只增加生命值。离屏起手、树冠遮挡和攻击范围必须在固定镜头下审查。战斗中翻阅详细图鉴暂停单机游戏，现场观察使用快捷记录，避免被菜单惩罚。

## 5. 地图与回访

采用可往返的地区地图，地区之间经山口、渡口或行旅节点连接。每个地区围绕一个聚落或营地、两至三条相连路线和一处关键地标组织，数量为灰盒建议。不开局铺满地图问号；远处可见的石门、异常叫声、河道变化和居民口述承担引导。

首次进入提供一个明确归途问题与至少两项局部调查，可自由选择调查次序，必要证据汇合后进入关键挑战。玩家可放置个人标记，任务记录说明已知地点与未解问题，可开启更明确的导航辅助。隐藏内容仍须有至少一条可重复获得的线索。

| 门槛 | 示例 | 防止卡死的规则 |
| --- | --- | --- |
| 知识 | 根据新发现的足迹特征识别旧河滩上的兽径 | 环境证据始终存在，理解后能直接尝试，不强制先点某行对话 |
| 能力 | 轻足跨过指定窄沟，打开侧路捷径 | 轻足在窄沟外的必经试炼获得；落点安全，基础归路不依赖跨越 |
| 世界阶段 | 水位变化露出旧渡口 | 安全等待或明确任务动作推进，不能等待现实时间 |

支路建议在 5～15 分钟内给出阶段回报，如新物种、试炼线索、特色器物或局部故事；这是节奏目标，不是强制每隔固定距离放宝箱。探索奖励分散使用，避免所有路径终点都只有材料。

新能力引导一次附近旧地回访，展示不同路径或观察角度；主线复用地区必须有新事件、新通路或已知关系变化。已到访安全节点开放快速旅行，战斗与不可中断事件中禁用；随时显示限制原因。首次旅途保留发现过程，长距离补漏降低重复跑图。

## 6. 成长、装备与收集

成长分三条：玩家掌握敌人动作；首次挑战取得新力量；武器与服装获得有限升级。原型不设置经验等级与等级压制，生命和药囊扩充由明确里程碑提供。是否需要等级系统在样段后评估，不能为延长 30 小时而默认加入刷级。

建议完整版本先以短矛、短刀、重兵器三个动作家族估算成本；首个样段只制作短矛。相同家族的铠化共享移动和基础动作，专属重击、特效与外形表达差异。新增家族需证明打法差异和动画预算，而非每种异兽再配一套完整武器动作。

服装按整套处理，附少量环境适应或防护特色；两件器物槽提供被动搭配。已取得的服装可选外观，铠化的有效攻击形态仍须真实显示。固定特色装备优先，升级建议少量节点、清楚列出收益，旧装备可保留独特用途。

常用材料来自可再生采集、交易与普通探索；独特升级凭证由固定挑战或任务确定授予，取得后不可误卖。普通装备出售前可预览，初始基础武器与唯一任务物保护。交易先用一种抽象交换凭证，聚落物资往来作为叙事表现；不引入复杂实时物价。

将“物种收录”“力量来源解锁”“武器服装拥有”分为三份清单。全图鉴不要求全部战斗，全部力量需要完成对应挑战；杀死友善异兽不是全收集捷径。观察型、不可挑战的神异存在显示收录目标，不显示虚假的未获得能力。

具体物种与奖励表须按来源逐条列出战斗或试炼、技能/武器/护具奖励、探索用途、备用获取渠道和资产成本。现有 60 物种（含 12 异兽）只是预算建议，不代表足以容纳所有章节和奖励。隐藏异兽首次奖励确定获得，重复同来源胜利不再新增能力。

## 7. 失败、保存与选择后果

战斗失败回到最近安全点或首领门前，恢复到该次重试的基础补给；不掉落永久图鉴、力量或装备，不跑尸捡回唯一财产。普通遭遇可以重置，任务已确认的结果不因休息复活。奖励与胜利一起保存，不能出现已经击败但奖励丢失。

采用独立的探索快照、路线前快照与当前进度；读取较早存档会恢复该存档的世界和收集状态，永久保留指当前连续进度中的死亡不回退，不表示跨所有存档合并。当前进度的自动保存、退出保存和手动存档范围需在实现阶段明确；战斗中退出建议恢复该遭遇开始状态，不能刷新奖励或冷却获利。

选择遵循发现处境、了解已知代价、采取行动、看到结果。重要分支不可逆前有明确提示；早期一句态度不锁死结局，装备强度和收集率不决定归家资格。四条候选结局沿用主线 E1～E4，主线提供所有基本机会；支线改变救援条件、地方结果与人物后日谈。

通关后的“继续探索（归途开启前）”加载探索快照，其新增收集不会改写已记录的结局；要带入新准备体验另一结局，需从该探索进度重新进入终章，建立新路线快照。结局记录只保存达成情况，不能把某结局的世界状态带进另一条路线。

## 8. 30 小时内的推进

| 阶段 | 新的玩家判断 | 成长与地图用途 |
| --- | --- | --- |
| P0，2 小时 | 如何生存、学习并获得第一力量 | 基础武器、狌狌友好试炼、轻足铠化和跨沟返回捷径 |
| P1，4 小时 | 旧记录与当前环境哪里不同 | 第二种能力搭配、路线调查次序、隐藏踪迹 |
| P2，4 小时 | 如何辨认具体个体的行为与立场 | 将观察用于战斗准备，试炼与冲突有不同后果 |
| P3，4 小时 | 归途试验缺了什么 | 根据已有打法选装备升级，旧能力组合用于遗迹 |
| P4，5 小时 | 怎样验证生境恢复 | 环境操作、守点战与回访，不增加另一套经营系统 |
| P5，5 小时 | 怎样利用时段而不是等待 | 安全点切换有限时段，组合既有能力应对路线变化 |
| P6，5.5 小时 | 为哪种归途方案行动并承担代价 | 共享地区中的不同目标与战斗，检验已有搭配 |
| P7，0.5 小时 | 看见自己的行动结果 | 短可操作尾声与独立结局记录，异兽关系得到回应 |

合计仍为 30 小时。现有 12 条支线的 10 小时预算独立保留；隐藏挑战若属于这些任务就计在其中，其余归额外探索。全收集总时长须待内容名录与样段实测后估算，不把主线、支线和同一观察重复相加。不同结局的重玩时间也不计入单次主流程。

## 9. 制作顺序与验收

按用户希望的大类验收，先验证一段完整体验再扩充全章。第一份样段为 P0 的 45～60 分钟，包含废墟拾书、北方山野与小聚落、短矛、小型普通野兽、狌狌试炼、强大异兽踪迹、轻足铠化、一条跨沟捷径、植物与动物各一条完整收录。废墟取书计入原前 10 分钟目标，不另加序章时长；狌狌已确定，其余物种另行选择，原典引用与造型参考在制作前校核。

| 验收面 | 后续试玩必须观察到的证据 |
| --- | --- |
| 初始战斗 | 不携带异兽能力能通过首次试炼；失败可重试且友方仍友好 |
| 拾书与知识 | 无书也能找到书匣；取书后才开始图鉴教学，重复拾取不重发，旧笔记不提前解锁轻足 |
| 铠化与装备 | 获得、装配、发动、切换、冷却、解除和读档行为一致，普通武器始终可用 |
| 探索 | 线索能让首次玩家找到目标；新能力打开侧路，缺隐藏能力仍可离开 |
| 收集 | 观察而非击杀可完成普通动物记录；重复事件不重复奖励 |
| 镜头与操作 | 键鼠和手柄都能识别预警、指向目标；遮挡不隐藏威胁 |
| 失败与进度 | 胜利后死亡保留奖励；重试不刷材料；旧档恢复不串入未来结果 |
| 主线与结局 | 只做主线仍有完整证据与四线机会；全收集不成为结局钥匙 |
| 成本与节奏 | 记录首次力量时间、迷路点、失败次数和每类资产工时，复核内容规模 |
