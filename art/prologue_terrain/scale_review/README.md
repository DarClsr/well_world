# 序章地图尺度评估

2026-09-08，读取 v05，未修改或保存原地图。

实际地形边界为 180×160 米，高度约 -0.05 至 25.87 米。
`map_scale_annotated.png` 为实际 Blender 正俯视渲染叠加设计路线，附 20 米比例尺。
`ruins_human_scale.png` 的红色人形为 1.75 米高的尺度标尺，不是正式角色。

根据地形脚本现有路径控制点计算平面折线长度：

| 路段 | 长度 |
| --- | ---: |
| 废墟至聚落 | 89.3 米 |
| 聚落至试炼坡 | 95.3 米 |
| 试炼坡至采药棚方向 | 97.2 米 |
| 采药棚经溪岸返回聚落 | 95.6 米 |
| 合计 | 377.3 米 |

上述数字不是导航或实走测量，未计高差。若假设移动速度 4 米/秒，
前两段单段约 22–24 秒，全部路线纯移动约 94 秒；这不是序章游玩时长，
没有包含战斗、剧情、搜寻或绕路，也未确认正式角色移动速度。

评估：出生废墟的建筑尺度可继续保留；区域之间的探索过渡较短，且路线
较直接。建议下一轮优先增加废墟下山段的山脊遮挡、溪谷过渡和可选岔路，
其次拓展东侧异兽探索区域。不要整体放大门口、房屋、树木来增加地图面积。
扩图尺寸应结合路线目标和引擎实走确定，本轮未扩图。

镜头观察：入口内侧角色可能被石梁遮挡。后续固定游戏镜头需检查门梁、
墙体遮挡处理；本轮为展示尺度将标尺移至院内无遮挡处，没有修复游戏镜头。

重建：Blender 后台运行 `tools/render_prologue_scale.py`，再用 Python/Pillow
运行 `tools/annotate_prologue_scale.py`。数据记录在 `measurements.json`。
