# 废墟模块第二版

2026-09-08。对应 `art/prologue_terrain/prologue_terrain_v05.blend`。
保留初版独立模型和 v04 地图，作为对比；本版仍待美术验收。

## 本轮调整

- 墙体石料宽度错落，收敛倒角和错位幅度，避免圆润积木感。
- 残墙改为不规则缺口，地图中调整朝向和高度，打破重复的阶梯轮廓。
- 石门立柱改为较大石料，维持原有入口尺度；台阶仍衔接约 0.35 米平台。
- 铺地改为变化尺寸的错缝石板，东南平台缺损，坍塌石料沿断墙和缺口布置。
- 降低石纹噪点对比，增加石料色差和低处少量暗苔色。材质使用纹理和
  `Weathering` 顶点色共同着色，GLB 明确导出 `COLOR_0`。
- 墙根增加 10 个既有蕨类/苔石碎石实例；原有 959 个素材实例保留。

## 文件与复用

`individual/` 包含八个独立 Blender 源文件；`ruins_module_library.blend`
为总览展示。对应 GLB、三张共享贴图、面数和尺寸清单位于
`assets/ruins_modules/v2/`。所有模块以米为单位，最低点归零，地图通过
28 个集合实例链接本版源文件。GLB 导入后应保留顶点色乘入基础色的材质设置。

`map_placements_v05.json` 记录 28 个废墟实例的位置、旋转和缩放。
新增的 10 个旧素材布景位于 Blender 的 `Ruins_Edge_Dressing_v05` 集合，
目前由生成脚本记录摆放，不包含在上述废墟清单中。

## 验证与边界

后台执行 `tools/build_ruins_modules.py` 重建本版，覆盖 v2 输出与 v05 地图。
手工修改前另存版本；不要通过重建来保存手工调整。
执行 `tools/check_ruins_modules.py` 检查八个独立源文件、UV、顶点色、
打包贴图、GLB 材质/颜色属性、28 个关联实例、10 个边缘布景与旧源文件哈希。
上述检查通过，模块总览及同角度地图预览已查看。

预览为 Blender 渲染。没有新增物理、坍塌动画或任务交互；Godot 行走、
碰撞及游戏镜头材质表现尚未验证。旧植物的造型风格仍需后续单独优化。
