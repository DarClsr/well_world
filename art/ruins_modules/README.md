## 复用方式

单位为米，Z 轴朝上，原点在地面高度的设计拼装中心。风化边缘会略超出
标称尺寸，实测包围盒和三角面数见 `manifest.json`。单件约 324–2916 三角面。
在 Blender 使用 Link 引入 `individual/*.blend` 的 Object，再以集合实例摆放。
v04 已使用此方式关联 8 个源文件，共 25 个实例；修改源文件后重载地图链接。
总览库内物体为展示排布，生产修改以 `individual/` 源文件为准。

三张 512×512 石材贴图分别为颜色、粗糙度、法线，源文件内已打包，GLB 内嵌。
各 GLB 导入引擎后可再统一为共享材质，不能假定引擎会自动去重。
移动地图时保持整个仓库的相对目录结构。摆放清单保存 Blender 坐标、弧度旋转
及缩放；到 Godot 的位置映射为 `(x, z, -y)`，旋转/缩放也须按坐标轴转换。

## 重建与验证

用 Blender 后台执行 `tools/build_ruins_modules.py` 可重建本组输出；会覆盖
本组生成文件，手工编辑前应另存版本。原 v03 和旧素材源文件不会被修改。
`tools/check_ruins_modules.py` 重开每个源文件，检查网格、原点、UV、贴图打包、
GLB 结构，再重开 v04 检查 25 个实例和旧素材哈希。

已完成 Blender 预览与文件检查。模块均为静态模型，没有新增坍塌动画、刚体、
碰撞、导航或任务逻辑。既有植物动画仍来自旧资产；Godot 运行验收待后续进行。
